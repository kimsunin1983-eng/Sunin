# 실시간 자막 번역 (Android)

폰에서 재생되는 영상 소리를 알아듣고 **한국어 자막을 다른 앱 위에** 띄워 주는 앱입니다.
음성 인식은 폰 내장 인식기, 번역은 Google 번역(인터넷, 안 되면 기기 내 ML Kit)을 써서 **API 키가 필요 없습니다.**

자막은 세 단계로 바뀝니다.
1. **흐린 글씨** — 말하는 도중의 임시 번역 (Google)
2. **조금 흐린 글씨** — 문장이 끝난 직후의 초벌 번역 (Google, 약 1초)
3. **선명한 글씨** — Gemini가 앞 대사 흐름을 보고 자연스럽게 다듬은 번역 (2~4초 뒤)

Gemini 키는 [aistudio.google.com/apikey](https://aistudio.google.com/apikey)에서 무료로 받아 앱 첫 화면에 붙여 넣으면 됩니다.
여러 문장을 묶어 4초에 한 번 이하로 보내므로 무료 한도(1분 약 15회) 안에서 동작하고, 한도를 넘으면 초벌 번역이 그대로 남습니다.
무료 등급에서는 보낸 대사가 Google의 모델 개선에 쓰일 수 있습니다.

```
영상 소리 ─▶ 폰 내장 음성 인식 ─▶ Google 번역(→ 한국어) ─▶ 떠 있는 자막 창
```

## 설치
1. 이 저장소의 **Releases → 최신 빌드 → `LiveSubtitle.apk`** 를 폰에서 눌러 내려받습니다.
2. "출처를 알 수 없는 앱 설치"를 허용하고 설치합니다.

코드를 고쳐 `main` 에 올리면 GitHub Actions 가 자동으로 새 APK 를 만들어 같은 자리에 올립니다.
항상 같은 키로 서명하므로 삭제 없이 덮어 설치할 수 있습니다.

## 사용
1. 영상 언어 선택 → **자막 시작**
2. 처음엔 권한 허용: 마이크, 다른 앱 위에 표시, 화면 공유(**'전체 화면'** 선택, 소리만 사용)
3. 유튜브 등에서 영상 재생 → 화면 아래에 자막
4. 자막 창: 끌어서 이동, **두 번 탭하면 종료**

## 소리 가져오기 방식
| 방식 | 조건 | 특징 |
|---|---|---|
| 폰 소리 직접 | Android 13 이상 | 이어폰 써도 됨. 넷플릭스 등 녹음 차단 앱은 안 됨 |
| 마이크로 듣기 | 모든 버전 | 스피커로 틀어야 함. 주변 소음 영향. 기기에 따라 인식 시작 때 '띵' 소리 |

## 문제 해결
- **자막이 안 나옴** → '오프라인 음성 인식 우선 사용'을 끄고 다시 시작 / '마이크로 듣기'로 바꿔 보기
- **"음성 인식 서비스가 없어요"** → Play 스토어에서 Google 앱, "Speech Recognition & Synthesis from Google" 업데이트
- 오프라인 인식은 해당 언어팩이 필요합니다: 설정 → Google → 음성 → 오프라인 음성 인식에서 언어 다운로드

## 한계
- 원본 언어는 직접 골라야 합니다 (내장 인식기는 자동 감지 불가).
- 임시 번역은 문장 중간이라 어색할 수 있고, 문장이 끝나면 바로잡힙니다.
- 인터넷이 없으면 기기 내 ML Kit 번역을 쓰며, 품질이 다소 떨어집니다.

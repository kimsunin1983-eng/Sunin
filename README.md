# 세로말 - 실시간 자막 대화 통역

> 세상의 말을, 서로의 말로. 영상은 자막으로, 대화는 내 언어로.
>
> 세로말은 '세상의 말을 서로의 말로 이어 준다'는 뜻을 담은 이름입니다. 서로 다른 언어로 말해도 각자가 이해할 수 있는 자막과 음성으로 전달해, 영상과 대화를 편하게 이해하도록 돕습니다.

안드로이드 앱입니다. 기능은 두 가지입니다.

- **자막 번역**: 폰에서 재생되는 영상 소리를 듣고 한국어 자막을 다른 앱 위에 띄웁니다.
- **대화 통역**: 두 사람이 각자 자기 언어로 말하면, 상대의 말을 번역해 듣는 사람 쪽 이어폰에만 들려줍니다.

## 설치
1. 이 저장소의 **Releases → 최신 빌드 → `LiveSubtitle.apk`** 를 폰에서 내려받습니다.
2. "출처를 알 수 없는 앱 설치"를 허용하고 설치합니다.
3. [aistudio.google.com/apikey](https://aistudio.google.com/apikey)에서 Gemini API 키를 무료로 받아 앱의 **설정**에 붙여 넣습니다.

`main` 에 코드를 올리면 GitHub Actions 가 새 APK 를 만들어 같은 자리에 올립니다. 항상 같은 키로 서명하므로 덮어 설치할 수 있습니다.

## 자막 번역

| 번역 방식 | 동작 | 특징 |
|---|---|---|
| 실시간 통역 | 소리를 `gemini-3.5-live-translate-preview` 에 흘려보내 바로 번역 | 가장 빠름. 언어 자동 감지. 데이터를 많이 씀 |
| 듣기 번역 | 소리를 문장(최대 6초) 단위로 잘라 Gemini 가 듣고 번역 | 2~4초 늦음. 언어 자동 감지 |
| 기본 | 폰 음성 인식 → Google 번역 → (키가 있으면) Gemini 다듬기 | 키 없이도 동작. 영상 언어를 직접 골라야 함 |

- 실시간 통역이 연결되지 않으면 듣기 번역으로, 그것도 안 되면 기본 방식으로 자동 전환합니다.
- 자막 창은 지난 문장을 포함해 2~4줄(설정)을 보여 줍니다. 끌어서 옮기고, 두 번 탭하면 끝납니다.
- 초벌 번역은 조금 흐리게 먼저 뜨고, "완성 번역으로 다듬기"가 켜져 있으면 몇 초 뒤 다듬어진 문장으로 바뀝니다.
- 소리 입력: **폰 소리**(Android 13 이상, 화면 공유 허용 필요, 녹음을 막은 앱은 불가) 또는 **마이크**.

## 대화 통역

폰을 두 사람 사이에 두고 폰 마이크로 듣습니다.

| 방식 | 동작 | 특징 |
|---|---|---|
| 실시간 (기본) | 대화용 실시간 모델 하나에 통역사 역할을 지시. 번역문의 글자 종류를 보고 재생할 귀를 정함 | 빠르고 목소리가 자연스러움. 드물게 번역 대신 대답할 수 있음 |
| 문장 단위 | 말이 끝나면 받아쓰기 → 글자로 언어 판단 → 번역·검사 → 폰 TTS 로 한쪽 귀에 재생 | 3~5초 걸림. 단계마다 검사 |

- **듣는 방법**: 이어폰을 한쪽씩 나눠 끼기, 또는 상대는 폰 스피커로 듣기(나만 이어폰, 화면 위에 상대가 읽을 뒤집힌 큰 글자 표시).
- **통역 설정**: 상황, 말투(존댓말/편한 말), 번역 목소리, 감정·어조 따라 말하기, 이름·자주 나오는 단어.
- **주변 소리 민감도**: 작은 목소리 증폭과 버리는 소리 크기를 함께 조절.
- 한쪽 언어를 **자동 감지**로 둘 수 있습니다(실시간 방식).
- 실시간 방식의 보조 동작: 모델이 놓친 말은 문장 단위 방식으로 다시 통역, 대화 기록의 원문은 언어를 알려 주고 다시 받아써 교정, 번역이 멈추면 자동 재연결, 재연결 시 최근 대화를 넘겨 맥락 유지.

대화 통역에 번역 전용 모델(`gemini-3.5-live-translate-preview`)을 쓰지 않는 이유: 한 방향 전용이고, 연결 후 처음 들은 언어에 맞춰져 번갈아 말하는 대화에서 언어를 잘못 듣습니다.

## 알아 둘 점
- Gemini 무료 등급에는 사용량 한도가 있고, 보낸 음성·대사가 Google 의 모델 개선에 쓰일 수 있습니다.
- API 키는 폰의 앱 저장소에만 저장되며 이 저장소에는 들어 있지 않습니다.
- 영어↔스페인어처럼 같은 글자를 쓰는 언어쌍은 글자로 말한 사람을 가릴 수 없어, 실시간 방식에서 번역이 양쪽 귀에 들립니다.
- 사용 모델 이름과 연결 설정은 Google 쪽 변경에 따라 바뀔 수 있습니다. 앱은 여러 조합을 차례로 시도하고 성공한 것을 기억합니다.

## 구조
```
app/src/main/java/com/example/livesubtitle/
  MainActivity.kt            홈·설정 탭
  CaptionService.kt          자막 번역 (포그라운드 서비스, 소리 캡처, 세 가지 번역 방식)
  SubtitleOverlay.kt         떠 있는 자막 창
  ConversationActivity.kt    대화 통역 화면과 두 가지 방식
  LiveTranslateClient.kt     Gemini Live WebSocket 클라이언트
  GeminiAudioTranslator.kt   듣기 번역 (자막)
  GeminiRefiner.kt           초벌 번역 다듬기 (자막)
  UtteranceTranslator.kt     문장 단위 통역 (대화)
  Transcriber.kt             언어를 알려 주고 받아쓰기 (대화 기록 원문 교정)
  Diagnostics.kt             연결 진단
  WaveView.kt                마이크 물결 표시
```
